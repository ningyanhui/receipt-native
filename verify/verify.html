Receipt-Native · 离线校验

粘贴 receipt JSON → 绿（Ed25519 验签通过）/ 红（失败）。纯前端 Web Crypto，可 file:// 打开，无需联网。算法见 verify-core.js（与 glass 共用）。

算法说明（须与 Node CLI 一致）
  • publicKey：标准 base64，raw 32-byte Ed25519 公钥
  • signature：标准 base64，raw 64-byte Ed25519 签名
  • 签名消息 = UTF-8(canonicalize(receipt 去掉 signature))
  • canonicalize：对象键字典序递归排序（与 src/crypto/digest.js 相同）
  • CLI：npm run verify -- path/to/receipt.json → 打印 green/red
  • 伪造对比：npm run forge-demo → 篡改 toolName，应验红
